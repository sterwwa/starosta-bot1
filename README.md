# 🎓 Сратоста Бот — Telegram Бот Старосты Студенческой Группы

Многофункциональный Telegram-бот для старосты и студентов с интерактивным веб-симулятором, админ-панелью, AI-генератором роастов/отмазок и **прямой синхронизацией с расписанием Российского университета кооперации (https://schedule.ruc.su/)**.

---

## ⚡ Быстрый старт локально

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/sratosta-bot.git
cd sratosta-bot

# 2. Установить зависимости
npm install

# 3. Настроить переменные окружения (.env)
cp .env.example .env
# Укажите в .env ваш токен Telegram бота от @BotFather:
# TELEGRAM_BOT_TOKEN="123456789:ABCDef..."
# GEMINI_API_KEY="AIzaSy..."

# 4. Запустить в режиме разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🚀 Развертывание на Amvera Cloud (amvera.ru)

Amvera — российский облачный сервис, отлично подходящий для круглосуточной работы Telegram-ботов и Node.js приложений.

### Шаг 1. Загрузка кода на GitHub
1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `sratosta-bot`).
2. В папке проекта выполните команды в терминале:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Sratosta Bot with RUC schedule sync"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/sratosta-bot.git
   git push -u origin main
   ```

### Шаг 2. Создание проекта в Amvera
1. Зарегистрируйтесь или войдите на [amvera.ru](https://amvera.ru).
2. Нажмите **«Создать проект»**.
3. Выберите тип: **«Приложение»**.
4. В качестве источника выберите **GitHub** и привяжите созданный репозиторий `sratosta-bot`.
5. Выберите ветку `main`.
6. Amvera автоматически обнаружит файл `amvera.yml` или `Dockerfile` из корня репозитория.

### Шаг 3. Переменные окружения в Amvera
В панели управления проектом на Amvera перейдите во вкладку **«Переменные»** и добавьте:
- `TELEGRAM_BOT_TOKEN`: токен вашего бота от `@BotFather`
- `GEMINI_API_KEY`: ключ Google Gemini API (для AI-роастов и генератора отмазок)
- `PORT`: `3000`
- `NODE_ENV`: `production`

### Шаг 4. Деплой
Нажмите кнопку **«Собрать и развернуть»**. Бот автоматически скомпилируется и запустится!

## 📅 Синхронизация с сайтом расписания РУК (https://schedule.ruc.su/)

Бот умеет в один клик получать официальное расписание пар с портала Российского университета кооперации:
1. Откройте вкладку **«Синхронизация РУК»** в веб-панели.
2. Выберите ваш филиал (Головной вуз, Владимирский, Волгоградский, Казанский и др.).
3. Выберите год набора (например, `НАБОР 2024 ГОДА`).
4. Выберите вашу учебную группу (например, `БД1-О/СПОо/ГВ24`).
5. Нажмите **«Синхронизировать с ботом»** — все пары, преподаватели, аудитории и типы занятий мгновенно запишутся в бота!

## 🤖 Основные команды бота в Telegram (@sratosta_bot)

| Команда | Описание |
|---|---|
| `/start` | Главное меню бота с интерактивной клавиатурой |
| `/today` | Расписание пар на сегодня с аудиториями и звонками |
| `/tomorrow` | Расписание на завтра |
| `/week` | Полное расписание на неделю (Числитель / Знаменатель) |
| `/dz` | Актуальные домашние задания и дедлайны |
| `/duty` | Кто дежурный сегодня (мытье доски, мел, проветривание) |
| `/debt` | Список должников и несданных лабораторных |
| `/fund` | Сбор средств группы (день рождения препода, распечатки) |
| `/roast` | AI-отчитывание от старосты за прогулы |
| `/excuse` | Генератор отмазок для преподавателя и деканата |
| `/quote` | Цитата дня из жизни группы и преподавателей |
| `/poll` | Быстрый опрос посещаемости первой пары |
| `/help` | Список всех доступных возможностей |
